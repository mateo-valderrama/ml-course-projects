# Assignment 3: Unsupervised Learning

## Objective
To cluster countries according to their risk for foreign investment using different clustering techniques.

## Dataset
Data from 122 countries and the following features:
- Corruption index
- Peace index
- Legal risk index
- GDP growth rate, in percentage

## Methods Used
- K-means clustering
- Agglomerative Hierarchical Clustering
- Scikit-Learn Library

## Results
- Visualization for pairwise scatter plots (before and after)
- 3 distinct clusters with both methods
