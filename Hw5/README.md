# Assignment 5: Machine Learning Classification Models

## Objective
Test four different classification models - Linear Discriminant Analysis (LDA), Logistic Regression, K-Nearest Neighbours (KNN), and Decision Trees – to evaluate their default classifer and later tune hyperparameters using a 3-fold cross-validation.

## Dataset
- Pre-split training and test sets (train_data.csv and test_data.csv)
- Containing features used for credit card approvals (e.g. debt, age, occupation, debt-to-income ratio, income, education, etc.)

## Methods Used
- Scikit-learn for model creation
- GridSearchCV for cross-validation and model selection

## Results
- Visualization of each model's ROC curve and metrics
- Key Results of models before and after cross-validation
