# Assignment 6: Natural Language Processing (NLP)

## Objective
Conduct descriptive analysis and Latent Dirichlet Analysis (LDA) to create a model to extract themes from a sample of transcripts of US public firms.

## Dataset
- Conference call transcripts from US public firms in Q4 2019

## Methods Used
- Latent Dirichlet Analysis (LDA), both unguided and guided
- SpaCy and gensim libraries for NLP
- Matplotlib for visualization of outliers and skew in the text data

## Results
- Deeper understanding of the application of NLP to real-world communication and text data, like we see in public firm earnings calls.
- Increased preprocessing with the corpus and bag of words dictionary can help to decrease incoherent topic words with filler-words such as ‘yeah’ and ‘like’.
- Some additional model tuning on hyperparameters (e.g., alpha, number of passes, number of topics) might help in refining topic outputs.
