# Machine Learning Portfolio

This repository showcases a collection of projects completed as part of a machine learning course. Each project focuses on applying different ML algorithms and concepts to real-world datasets and problems, using Python and popular libraries like scikit-learn, pandas, matplotlib, and scipy.

## Contents
- Linear Regression
- Logistic Regression
- Decision Trees
- Support Vector Machines
- Neural Networks
- Unsupervised Learning (Clustering, PCA)

Inside each assignment folder, the README will explain:
- The objective of the assignment
- The dataset used
- The ML methods applied
- Key takeaways or results
